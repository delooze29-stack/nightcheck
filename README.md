# Night Check

SK Distribution nightly pallet measure check.

1. Load the Palletways Consignment Analysis exports and print the measure sheet.
2. Enter the measurements (S70 / E80, or full L W H for oversize).
3. See what to change on Palletways, the charge, and the extra revenue.

Use **Load night file** to open a night saved from the Claude version (photo reading).
Saved night files hold customer data – keep them off this repo.
